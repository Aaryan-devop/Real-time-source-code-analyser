# Push CodePulse to GitHub

## Quick Method (Automated Script)

```bash
# Run the automated script
cd /Users/apple/Downloads/codepulse
chmod +x push-to-github.sh
./push-to-github.sh
```

---

## Manual Method (Step by Step)

### Step 1: Navigate to Project
```bash
cd /Users/apple/Downloads/codepulse
```

### Step 2: Fix Git Permissions (if needed)
```bash
sudo chown -R $(whoami) .git
```

### Step 3: Configure Git User
```bash
git config user.name "Aaryan Developer"
git config user.email "aaryan@devop.local"
```

### Step 4: Stage All Files
```bash
git add .
```

### Step 5: Create Commit
```bash
git commit -m "Initial commit: Complete CodePulse project

Real-time Code Quality Analysis Platform

Features:
- Real-time static analysis (<50ms feedback)
- 100% local execution (zero telemetry)
- Multi-language support (JavaScript/TypeScript/Python)
- Security scanning (secrets, SQL injection, XSS)
- Interactive dashboard with health scores
- WebSocket-based live updates
- Git integration with change tracking

Tech Stack: React 19, TypeScript, Node.js, Express, SQLite

Co-Authored-By: Claude <noreply@anthropic.com>"
```

### Step 6: Add Remote Repository
```bash
git remote add origin https://github.com/Aaryan-devop/Real-time-source-code-analyser.git
```

### Step 7: Rename Branch to Main
```bash
git branch -M main
```

### Step 8: Push to GitHub
```bash
git push -u origin main
```

---

## If Repository Already Has Files

If you've previously pushed some files and want to force push everything:

```bash
git push -u origin main --force
```

⚠️ **Warning**: `--force` will overwrite any existing commits on GitHub. Use only if you're sure!

## Troubleshooting

### Permission Denied Error
```bash
sudo chown -R $(whoami) .git
chmod -R u+w .git
```

### Remote Already Exists
```bash
git remote remove origin
git remote add origin https://github.com/Aaryan-devop/Real-time-source-code-analyser.git
```

### Authentication Failed
```bash
# Use GitHub Personal Access Token
# Settings → Developer settings → Personal access tokens
# Generate token with 'repo' scope
# Use token as password when prompted
```

### Already Up to Date
```bash
# Force push (overwrites remote)
git push -u origin main --force
```
